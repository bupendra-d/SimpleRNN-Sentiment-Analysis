# SimpleRNN Sentiment Analysis
A simpledeep learning project that classifies IMDB movie reviews as positive or negative using a Simple Recurrent Neural Network (SimpleRNN).

### Features
- IMDB movie review dataset
- Text sequence preprocessing and padding
- Embedding and SimpleRNN layers
- Early stopping and model evaluation
- Interactive Streamlit application

### Tech Stack
Python · TensorFlow/Keras · NumPy · Streamlit
